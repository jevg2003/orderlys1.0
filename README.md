# Orderly’s

## Resumen

Sitio de presentación de Orderly’s, una propuesta para digitalizar la atención y los pedidos de negocios gastronómicos. Reúne la explicación del servicio, indicadores ilustrativos y secciones sobre el equipo.

## Qué encontrarás

- Portada y secciones de propuesta, misión, visión y equipo.
- Indicadores ilustrativos de utilidad y secciones de testimonios e información.
- Componentes Astro para armar la página y estilos con Tailwind CSS.

## Desarrollo local

```bash
pnpm install
pnpm dev
```

La entrada es [src/pages/index.astro](src/pages/index.astro). Para compilar la versión estática, ejecuta `pnpm build`.

## English summary

A website presenting Orderly’s, a proposal to digitize service and ordering for food businesses. It explains the concept and includes illustrative indicators and team sections.
